## iconfont 图标按分类展示

在 iconfont 项目详情页右下角提供「按分类展示」开关，根据 `project_icon_name` 第一段（如 `菜单-首页-默认` → `菜单`）对图标进行分组，分组标题吸顶，支持一键还原原始列表。开关状态持久化，刷新后自动恢复。
